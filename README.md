SE_Project10_React (se_project10_react)

This project uses REACT technology wich is a hybrid-combination of HTTM and JavaScript and CSS using a Vite environment through NPM. It connects API weather server delivering current weather for "what to wear" for each day according to weather conditions.

The project can be viewed at [(https://tamaraheater.github.io/se_project10_react)]

This project will be continually expanded for 3 more Sprints, with backend management in an additional Sprint.

# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh
